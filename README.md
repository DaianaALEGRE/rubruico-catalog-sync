# Rubrico Scraper

Proyecto desarrollado en Node.js para extraer automáticamente el catálogo de productos de Rubrico Mayorista.

## Objetivo

Obtener información de los productos para alimentar una base de datos propia utilizada por una tienda minorista.

## Características

- Obtención automática del catálogo.
- Extracción de nombre, precio, descripción e imágenes.
- Exportación a JSON.
- Actualización automática del catálogo.
- Preparado para integrarse con Supabase.

## Tecnologías

- Node.js
- Axios
- Cheerio

## Próximas mejoras

- Actualización automática de precios.
- Descarga de imágenes.
- Sincronización con Supabase.
- Dashboard de actualización.

## Instalación

```bash
npm install
```

## Ejecutar

```bash
node index.js
```
